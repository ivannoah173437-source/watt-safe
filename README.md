# 🔌 WattSafe - Alerte de coupure électrique

## 📖 À propos
WattSafe est une application web progressive (PWA) qui aide les utilisateurs de compteurs prépayés en Afrique à anticiper les coupures d'électricité.

## 🎯 Problème
Les utilisateurs subissent des coupures brusques sans alerte.

## 💡 Solution
- Estimer la date d'échéance du crédit
- Alerter avant la coupure
- Paiement Mobile Money (GeniusPay)
- Fonctionne hors-ligne

## 🛠️ Technologies
- HTML5 / CSS3 / JavaScript Vanilla
- PWA (Service Worker + Manifest)
- localStorage
- GeniusPay
